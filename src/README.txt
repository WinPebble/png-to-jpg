PNG to JPG Context Menu v8 (short label)
========================================

This build uses your icon and shortens the menu label to:
Convert PNG to JPG

Install / update
1. Extract the ZIP.
2. Double-click UPDATE_MENU.bat.
3. If the old label or icon still appears, restart Windows Explorer from Task Manager.

Notes
- Output JPG quality: 100
- Original PNG is preserved
- Transparent areas become white
- JPG is created in the same folder
- If a JPG already exists, a new file like _1, _2... is created
